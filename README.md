# Guitar Tool 吉他指板学习工具

一个在吉他指板上可视化显示音阶、根音、和弦内音等信息的学习与练习工具。

**在线使用**：https://2000x.github.io/guitar-tool/ （把这个网址发给别人就能用，电脑、平板、手机的浏览器都能打开；自检页：https://2000x.github.io/guitar-tool/自检.html）

## 使用方法

- **打开工具**：打开上面的在线网址；或者在本机双击 `index.html`（不需要联网）。
- **和弦**：选和弦根音和类型（28 种，按类别分组：三和弦、挂留/强力、六和弦、七和弦、九和弦及以上）。绿色圆点是延伸音（6、9、11、13 和 sus 的 2、4）。
- **顺阶和弦**：选好音阶后，“顺阶和弦”一行会列出这个调的 7 个和弦，点一下就显示在指板上，再点一下关闭；可切换三和弦/七和弦。键盘：1～7 选和弦、0 或 Esc 关闭、T 切换三/七和弦。
- **识别和弦**：点选择栏的“识别和弦”，然后在指板上点你按的位置（每根弦一个，再点取消；没点的弦算不弹 ×），下面会显示这是什么和弦，缺了哪些音；点识别结果就能在整个指板上看这个和弦。按 Esc 退出。识别时灰色圆点是这个和弦的音在其他位置（淡色虚线 = 你没按到的音），可用“显示其他位置”开关关掉。
- **调整品数**：选择栏“指板 · 品数”，可选 12～24 品。
- **调整界面大小**：指板会自动占满窗口宽度；右上角“A− / 100% / A+”放大缩小文字和按钮（点百分比恢复 100%）。
- **切换深浅模式**：右上角“跟随系统 / 浅色 / 深色”，浏览器会记住你的选择。
- **调颜色**：点右上角“调色”，改完满意后点“复制配置”，把内容发给 Claude 写进配置文件。
- **检查工具有没有出错**：双击 `自检.html`，全部是绿色 ✓ 就说明乐理计算正确。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 工具本体（打开这个） |
| `自检.html` | 自检页：列出所有乐理检查项和结果 |
| `css/style.css` | 外观：字体、排版、线条（不写具体颜色） |
| `js/theme.js` | **颜色配置**：所有颜色都在这里，每项有中文名，浅色/深色各一套 |
| `js/theme-ui.js` | 深浅模式按钮和调色面板 |
| `js/theory.js` | 乐理核心：音名、调弦、音阶、和弦的计算，不涉及界面 |
| `js/app.js` | 界面：把指板画出来、处理点选 |
| `tests/cases.js` | 全部乐理检查项（自检页和命令行测试共用） |
| `tests/run.js` | 命令行运行乐理检查（Claude 用） |
| `tests/ui_check.js` | 自动浏览器检查界面并截图（Claude 用） |
| `docs/需求文档.md` | 要做什么、乐理规则、验收标准、测试方式 |
| `CHANGELOG.md` | 每个版本改了什么 |
| `.gitignore` | 告诉 Git 忽略哪些无关文件 |
| `.nojekyll` | 告诉 GitHub Pages 原样发布这些文件（不要加工） |
